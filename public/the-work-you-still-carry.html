A steadier way to meet change

What you have learned still matters.

Change can arrive as a different kind of work, a new tool, a shift in a family, a quieter season, or a question that has not had a name yet. This book offers ten honest questions, room to think, and small private practices that can help you notice what you already carry.

Technology appears only as part of a changing world. This is not a technology course, a business opportunity, or a demand to “keep up.” It is a humane companion for reflection, choice, contribution, and care.

How to use this book

There is no program to keep up with.

Read one chapter in an evening, listen while walking, return to a question that stays with you, or leave a reflection page blank. The next step, if there is one, remains yours to choose.

  1. Start with the chapter that speaks to the question in front of you.
  2. Read, listen, or use both together.
  3. Treat each practice as an invitation, not an assignment.
  4. Keep what is useful. Leave what is not.
